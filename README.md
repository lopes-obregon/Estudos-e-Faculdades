## 🚀 Como Explorar os Projetos

Para clonar e inspecionar os projetos contidos neste repositório:

1.  **Clone o repositório para sua máquina local:**
    ```bash
    git clone [https://github.com/lopes-obregon/Estudos-e-Faculdades.git](https://github.com/lopes-obregon/Estudos-e-Faculdades.git)
    ```
2.  **Navegue até o diretório do projeto desejado:**
    ```bash
    cd Estudos-e-Faculdades/Programas-faculdade/SI/linguagem-de-programacao-2/ProjetoBase/JogosOlimpicos
    ```
3.  **Abra o projeto em seu Ambiente de Desenvolvimento Integrado (IDE) preferido.**
